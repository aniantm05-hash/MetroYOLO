## Что подтверждено с разной точностью

**Повторно измерено:** baseline на всех 21 validation-кадре. В Git есть per-image CSV,
конфигурация запуска, хеши данных и весов. Округлённые агрегаты совпали с отчётом.

**Сохранено в исходном выводе Colab:** training log, detection-метрики по эпохам,
финальная проверка best.pt и вывод ячейки 10EPOCH. Это исторические измерения,
не новое GPU-обучение в этой среде.

**Зафиксировано в отчёте:** count MAE 1,90 и load MAE 9,52 одного дообученного запуска,
неудача рассмотренной сетки порогов и визуальные наблюдения короткого запуска.
Эти результаты включены с указанием источника; их не следует выдавать за новый rerun.

**Не сохранилось:** исторические дообученные веса, CSV их предсказаний и полный
рейтинг 350 настроек. Из этого следует ограничение воспроизводимости, но не повод
исключать описанные в отчёте эксперименты из истории проекта.

## Проблема названий запусков

В отчёте основная команда использует имя metro_yolov5s, а сохранённый notebook
запускает 30 эпох с именем metro_yolov5s_e10. Оценка с подписью 10EPOCH загружает
тот же путь. Поэтому вывод ячейки сохранён как есть с описанием несоответствия.
Сам факт 30-эпохового обучения подтверждает лог; происхождение конкретного
checkpoint короткого запуска независимо не установлено.

## Что добавлено при оформлении репозитория

Модульный пакет, аудит переданного архива, повторная оценка baseline, приложение,
тесты, CLI и графики из сохранённых данных. Это программная упаковка исходной работы.
График ошибки 1,05 → 1,90 использует числа из отчёта и прямо подписывает их статус.
Новые эксперименты с обучением, скоростью или архитектурами не заявляются.
